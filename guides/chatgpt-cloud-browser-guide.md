# ChatGPT 云端浏览器怎么用？入口、公开网页限制与常见故障排查

**直接答案：**ChatGPT cloud browser（云端浏览器）从 **Work** 任务中使用，适合让 ChatGPT 在远程浏览器里访问受支持的公开网页、整理信息或填写公开表单。开始时应写清网站、目标、限制和交付结果；任务一旦要求登录、验证码或付款，就应停止，不能把密码或支付资料发给 ChatGPT。

OpenAI 当前说明，cloud browser 面向受支持地区的付费 ChatGPT 计划开放，但不包括 Free 和 Go，而且功能仍可能分批上线。即使你的套餐符合条件，也应以当前账号和工作区实际显示为准，不要为了寻找入口重复购买会员。

> 旧的 ChatGPT Agent mode 已停止提供。需要多步骤工作时使用 [ChatGPT Work]({{ '/guides/chatgpt-work-guide/' | relative_url }})；需要处理受支持的公开网页时，Work 可以调用 cloud browser。本文不介绍旧 Agent mode，也不涉及 OpenAI API。

## 先判断：你需要哪一种浏览器

“云端浏览器”“桌面端内置浏览器”和“Codex Chrome 扩展”解决的问题不同。先根据任务选择入口，可以避免把登录信息交给不支持登录的工具。

| 任务需要 | 应选工具 | 你会看到什么 | 关键限制 |
|---|---|---|---|
| 访问公开网页，任务可在后台继续，不需要登录或付款 | ChatGPT cloud browser | Work 中的任务进度、结果、链接或截图 | 不能登录网站、使用密码管理器或完成付款 |
| 在 ChatGPT 桌面应用里查看、批注、登录网页或下载文件 | 桌面端内置浏览器 | 一个可以观察和操作的应用内浏览器 | 使用独立浏览器状态，不会自动继承 Chrome 登录 |
| 必须使用现有 Chrome 登录状态、标签页或扩展 | Codex Chrome 扩展 | Codex 在你授权的 Chrome 环境中操作 | 必须核对当前账号、标签页和授权范围 |
| 只要读取 Gmail、Google Drive 等已连接服务的数据 | 对应 ChatGPT App | Work 直接调用已授权的 App | 先核对第三方账号和最小权限 |

如果连接的 App 已经可以直接完成任务，ChatGPT 可能不会启动 cloud browser。需要了解 App 连接和权限时，可阅读 [ChatGPT Apps 连接、权限与排障]({{ '/guides/chatgpt-apps-connectors/' | relative_url }})。

## 开始前先完成 4 项检查

### 1. 确认当前 ChatGPT 账号

打开 ChatGPT 的账号菜单，核对登录邮箱、登录方式和当前计划。不要只看浏览器里保存了哪个 Google 或 Apple 账号，因为 ChatGPT 当前会话可能登录的是另一个账号。

**预期结果：**你能够确认当前账号的登录方式，并且计划不是 Free 或 Go。

**如果不符合：**先切换回正确账号。已有有效订阅、成功扣款或待处理交易时，不要再次购买。

### 2. 确认 Work 可以使用

在 ChatGPT 网页、移动端或桌面端中查找 **Work**。个人付费计划的功能也可能受地区、分批开放和应用版本影响；单位账号还可能受工作区管理员权限控制。

**预期结果：**可以新建 Work 对话，或在已有 Project 中选择 Work。

**如果没有入口：**先更新应用、重新登录正确账号，并让工作区管理员检查 Work Cloud 和浏览器权限。上述条件都正确但仍没有入口时，再联系 OpenAI Support。

### 3. 确认目标网页无需登录和付款

第一次测试应选择公开网页，例如官方新闻页、公开商品目录或无需账号的查询页面。不要选择网银、邮箱登录页、需要验证码的页面，也不要把“帮我完成付款”作为 cloud browser 任务。

**停止条件：**任务必须输入密码、验证码、银行卡资料或完成支付时，立即停止。

### 4. 写清楚验收标准

开始前先决定怎样判断任务完成。例如，要求结果必须包含标题、日期和原始链接，而不是只写“帮我看看最近更新”。明确的验收标准可以减少错误网站、遗漏来源和无法核对的结论。

## 第一次安全测试：只访问公开网页

第一次使用时，不要同时连接邮箱、填写表单和比较多个网站。先用一个公开网站完成一个可以核验的小任务。

可以把下面的模板粘贴到 Work，并替换方括号中的内容：

> 请使用公开网页访问 `[网站名称或完整网址]`。
>
> 目标：找到 `[需要的信息]`。
>
> 限制：不要登录、不要提交表单、不要访问其他网站、不要进行任何付款或预订。
>
> 输出：列出 `[字段一]`、`[字段二]` 和原始页面链接；无法确认的信息请明确写“未确认”。

例如：

> 请访问 xAI 官方新闻页，列出最近三条与 Grok 消费端有关的更新。每条包含标题、发布日期和官方链接。不要登录，不要访问第三方媒体，也不要根据标题猜测正文内容。

这项测试只使用公开网页，结果也可以回到官方链接逐条核对，适合确认 cloud browser 是否能在当前账号正常工作。

## 完整操作流程

### 第一步：打开 ChatGPT Work

1. 登录 ChatGPT；
2. 在当前界面选择 **Work**；
3. 新建对话，或打开与本次任务相关的 Project；
4. 如果页面要求选择云端或本地环境，公开网页的后台任务应使用可用的云端 Work。

**预期结果：**输入框处于 Work 对话中，而不是普通 Chat 或 Codex。

**异常分支：**如果只有 Chat，没有 Work，返回上一节核对计划、地区、版本和工作区权限。不要在普通 Chat 中假定它一定会启动 cloud browser。

### 第二步：按“网站、目标、限制、输出”发送任务

一条可执行的指令至少包含四部分：

1. **网站：**指定网站名称或完整网址；
2. **目标：**说明需要查找、比较或填写什么；
3. **限制：**说明不能登录、不能付款、不能访问哪些网站；
4. **输出：**列出需要返回的字段、链接和格式。

**预期结果：**ChatGPT 能够复述任务目标，并开始访问正确网站；如果信息不足，它会先提问。

**停止条件：**如果它打开了错误网站、使用了错误日期或准备执行超出指令的操作，应立即停止并改写任务，不要等到最后再纠正。

### 第三步：审查确认请求

当操作可能产生难以撤销的结果，或涉及价格、账号和现实承诺时，ChatGPT 可能暂停并要求确认。确认前逐项检查：

- 当前网站是否正确；
- 接收方、日期、商品或服务是否正确；
- 页面显示的价格和账号变化是否符合预期；
- 即将执行的动作是否在原任务范围内。

**不要确认的情况：**页面需要登录、验证码、支付资料，或即将提交你没有要求提交的内容。当前 cloud browser 不支持登录和付款，遇到这些步骤应结束任务。

### 第四步：允许任务在后台运行

cloud browser 任务可以在你离开当前对话后继续。它需要补充信息或确认时会暂停；网站要求登录时会停止。

**预期结果：**任务继续显示进度，完成后返回结果和来源。

**异常分支：**如果任务长时间没有变化，先打开对话查看是否正在等待你的回答。不要连续创建多个相同任务，否则可能得到重复表单或难以分辨的结果。

### 第五步：验收结果，而不是只看“已完成”

任务结束后，按下面顺序检查：

1. 打开返回的原始链接；
2. 核对网站域名、标题和日期；
3. 将关键数字与网页原文逐项比较；
4. 确认没有遗漏你要求的字段；
5. 检查任务是否进行了未经批准的提交或修改。

如果结果缺少来源，先要求补充来源；如果来源无法支持结论，就把该结论标记为未确认。不要因为界面显示“完成”就直接用于付款、法律、医疗或其他高风险决定。

## cloud browser 能做什么，不能做什么

| 场景 | 当前是否适合 | 正确处理方式 |
|---|---|---|
| 浏览公开页面并整理标题、日期、库存或公开报价 | 适合，但取决于网站是否允许自动访问 | 指定网站和字段，完成后打开来源核对 |
| 在受支持的公开表单填写非敏感信息 | 可能适合 | 提交前检查接收方、字段和现实影响 |
| 使用连接 App 的数据查询公开物流或网页信息 | 可能适合 | 只启用必要 App，并核对数据来源 |
| 输入账号密码、验证码或恢复码 | 不支持 | 不要发到聊天；改用可见浏览器并由本人输入 |
| 使用自动填充或密码管理器登录 | 不支持 | 使用桌面端内置浏览器或现有 Chrome 会话 |
| 完成购买或付款 | 不支持 | 本人回到官方页面完成，并逐项核对订单 |
| 绕过 CAPTCHA 或网站反自动化限制 | 不支持 | 停止任务，改用自己的浏览器或其他公开来源 |

## 常见故障按这个顺序排查

### 情况一：Work 中没有启动 cloud browser

先确认任务是否真的需要网页。如果连接 App 可以直接完成，ChatGPT 可能会使用 App，而不是 cloud browser。

如果任务明确需要公开网页，再依次检查：

1. 当前账号是否为受支持的付费计划，而不是 Free 或 Go；
2. 所在地区是否受支持；
3. Work 是否已经在当前账号开放；
4. 单位工作区是否允许 Work Cloud 和浏览器访问；
5. 任务是否明确给出了公开网站和网页操作目标。

全部正确仍无法使用时，保存账号计划页面、Work 界面和报错文字的脱敏截图，再联系 OpenAI Support。不要通过重新订阅来测试入口。

### 情况二：任务停在登录页、验证码或 CAPTCHA

这通常说明网站进入了当前不支持的步骤，不等于会员失效。

1. 停止 cloud browser 任务；
2. 不要把密码、验证码或 Cookie 发到聊天；
3. 如果任务必须登录，在 ChatGPT 桌面端内置浏览器中由本人登录，或在确有必要时使用已授权的 Chrome 会话；
4. 登录后重新评估是否仍需要让 ChatGPT继续操作。

**停止条件：**网站明确禁止自动化访问，或要求绕过安全检查时，不应继续尝试。

### 情况三：网站在自己的浏览器正常，但 cloud browser 被拦截

网站可能限制自动化流量。限制由目标网站设置，因此更换 ChatGPT账号或反复重试通常无效。

正确顺序是：

1. 确认网址没有写错；
2. 只刷新或重试一次；
3. 仍被拦截时改用另一个可信公开来源；
4. 必须使用该网站时，在自己的浏览器中手动完成。

### 情况四：任务访问了错误网站或使用了错误信息

立即停止任务，并把错误点写进下一条指令。例如：

> 停止当前操作。只允许访问 `example.com`，日期范围是 2026 年 8 月 1 日至 8 月 15 日。不要使用搜索结果中的其他网站。先列出准备访问的页面，等待我确认后再继续。

如果错误涉及已连接 App，先核对连接的是哪个第三方账号。需要时到 Settings → Apps 断开错误账号，再按最小权限重新连接。

## 清理 Cookies 和远程浏览数据

cloud browser 使用远程浏览会话，访问网页时可能保存 Cookie。OpenAI 当前说明，这些 Cookie 不会让 cloud browser 在首发阶段获得登录能力，但完成敏感任务后仍应按需要清理。

在 ChatGPT 设置中查找浏览器数据或 Cookie 管理入口，删除不再需要的远程浏览数据。界面名称可能随版本变化，以当前设置页面为准。

桌面端内置浏览器使用另一套浏览器状态。如果你在内置浏览器登录过网站，需要在桌面应用设置中另行清除 Cookie、登录状态和浏览历史；清理 cloud browser 数据不会自动清理桌面端内置浏览器。

## 完成一次任务后的验收清单

- [ ] 当前任务使用的是正确 ChatGPT 账号和 Work；
- [ ] 访问的是指定公开网站，没有进入登录或付款步骤；
- [ ] 返回的域名、标题、日期和关键数字已经核对；
- [ ] 每个重要结论都有可以打开的原始来源；
- [ ] 没有提交未确认的表单、订单或现实承诺；
- [ ] 没有在聊天中发送密码、验证码、支付资料或恢复码；
- [ ] 不再需要远程 Cookie 时，已经清理浏览数据；
- [ ] 任务失败时只保留一条任务记录，没有反复创建重复任务。

## 套餐和订阅边界

OpenAI 当前说明，cloud browser 面向受支持地区的付费计划开放，但不包括 Free 和 Go，具体开放仍可能因账号、地区和工作区而不同。付费并不等于功能一定立即出现，也不能保证目标网站允许自动访问。

如果当前账号没有有效或待处理订阅，并且你确认需要符合条件的 ChatGPT 会员，可以先比较官方实时计划。没有海外付款方式时，[ChongGrok ChatGPT 会员页面](https://chonggrok.com/chatgpt)可作为使用支付宝或微信升级自己账号的一种选择；该服务与 OpenAI 无隶属关系，也不承诺 cloud browser 一定立即开放。

已有扣款、待处理交易或有效会员时，不要再次购买。应先核对当前账号、原购买渠道和功能开放状态。

## FAQ

### cloud browser 是一个单独的按钮吗？

不一定。当前官方流程是先打开 ChatGPT Work，再描述需要完成的公开网页任务。ChatGPT 会在合适时使用 cloud browser；如果 App 可以直接完成任务，也可能改用 App。

### cloud browser 可以在我关闭页面后继续吗？

可以在后台继续。需要补充信息或确认时会暂停；网站要求登录时会停止。稍后应回到原对话查看状态，不要另建相同任务。

### 可以让 cloud browser 帮我登录账号吗？

不能。当前版本不接收登录凭据，也不使用自动填充或密码管理器。需要登录时，应改用桌面端内置浏览器并由本人输入，或在确有需要时使用现有 Chrome 会话。

### cloud browser 可以帮我付款吗？

不能。它不能完成付款。涉及价格、预订、订单或现实承诺时，还应检查确认页面，并由本人完成最终步骤。

### 任务失败是否说明 ChatGPT 会员有问题？

不一定。常见原因还包括网站阻止自动化访问、任务进入登录或 CAPTCHA、Work 权限未开放、网址错误或指令不清。应先按本文顺序定位问题，再决定联系网站、工作区管理员或 OpenAI。

### 使用公开网页还需要注意隐私吗？

需要。网页可能包含诱导工具偏离任务的内容。应限定网站和目标、关闭不需要的 Apps、检查每次确认，并在发现错误网站或错误信息时立即停止。
