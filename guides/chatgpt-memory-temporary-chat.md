# ChatGPT 记忆怎么开启、查看和删除？Memory、聊天记录与临时聊天完整指南

**直接答案：**打开 `Settings → Personalization → Memory`，可以查看当前账号的记忆设置，并按页面提供的选项开启、关闭、纠正或删除记忆。只想进行一次不使用个性化记忆的对话时，应新建 **Temporary Chat（临时聊天）**；仅关闭训练开关，不能代替删除记忆或使用临时聊天。

删除聊天、关闭记忆和关闭“Improve the model for everyone”是三种不同操作。需要彻底移除一项个人信息时，应同时检查记忆摘要或已保存记忆、包含该信息的聊天和归档聊天、上传文件以及连接应用。

> 本文只解决 ChatGPT 个性化记忆和数据设置问题。OpenAI 正在滚动更新新版 Memory，不同计划、地区和设备看到的名称与入口可能略有不同，请以当前账号的实时页面为准。

## 先分清 5 个容易混淆的设置

如果把“记忆”“聊天历史”和“训练”当成同一件事，很容易在错误位置反复删除。先根据目标确认应该操作哪一项。

| 设置 | 它解决什么问题 | 它不会自动做什么 |
|---|---|---|
| Memory / Memory summary | 让 ChatGPT 使用对话、文件或连接应用中的有用信息进行个性化 | 关闭后不会自动删除旧聊天和已有记忆 |
| Saved memories | 保存姓名、偏好、目标等以后需要继续使用的信息 | 删除原聊天不会自动删除这部分记忆 |
| Reference chat history | 从过去聊天中提取有用背景 | 不保证记住每个细节，也不等于固定保存一项记忆 |
| Temporary Chat | 开始一次不使用或创建个性化记忆的对话 | 不会自动关闭 Custom Instructions，也不能控制第三方 Action 怎样处理收到的数据 |
| Improve the model for everyone | 控制普通对话是否用于改进模型 | 关闭它不会清除记忆，也不会删除聊天历史 |

因此，先回答一个问题：你是想让 ChatGPT **以后不再提到某项信息**，还是只想让 **本次对话不使用记忆**？前者需要管理并删除记忆来源，后者使用临时聊天即可。

## 第一步：进入当前账号的记忆设置

1. 打开 ChatGPT，并确认右上角或侧边栏显示的是自己的账号；
2. 点击头像或账户菜单；
3. 进入 `Settings`；
4. 选择 `Personalization`；
5. 打开 `Memory` 或当前页面显示的记忆入口。

**预期结果：**页面会显示 Memory 开关、Memory summary（记忆摘要）、Saved memories 或 `Reference chat history` 中的部分选项。

如果完全看不到这些选项，先不要重新购买订阅。检查 App 是否为最新版本，再在网页版查看同一账号；仍没有入口时，说明当前计划、地区、工作区或设备可能尚未获得对应界面。

## 第二步：查看 ChatGPT 当前记住了什么

新版界面可以在 **Memory summary** 中查看记忆摘要。摘要会概括 ChatGPT 当前用于个性化的重要信息，但 OpenAI 明确说明，它不一定显示系统可能使用的全部背景。

按下面的顺序核对：

1. 打开 `Settings → Personalization → Memory`；
2. 进入 `Memory summary` 或 `Manage`；
3. 阅读摘要中的姓名、偏好、目标、工作背景等内容；
4. 回到普通聊天，询问“你目前记住了关于我的哪些信息？”；
5. 比较回答与设置页，标记错误、过期或不希望继续使用的信息。

部分账号还会在回答下方显示书本形状的来源图标。点击后，可以看到这次回答使用了哪些记忆、过去聊天、文件或自定义指令。该来源列表有助于定位问题，但不能保证显示影响回答的每一个因素。

如果 Memory summary 为空，先确认记忆已经开启。新账号、刚开启记忆的账号或聊天历史较少的账号，可能暂时没有可显示的摘要；页面提供 `Refresh` 时，可以刷新一次后再检查。

## 第三步：纠正错误或过期的记忆

发现错误信息时，不要先删除整个账号或全部聊天。先在记忆摘要中纠正具体内容。

1. 在 Memory summary 中找到错误描述；
2. 页面允许直接编辑时，在摘要下方输入正确内容；
3. 页面允许选中文字时，选中错误部分并提交更正；
4. 回到新聊天，再问一次 ChatGPT 记住了什么；
5. 确认新回答已经使用更正后的信息。

例如，摘要仍写着“正在准备研究生考试”，但这件事已经结束，可以把它改为当前目标。这样比单纯要求“以后不要提”更清楚，也能减少旧信息继续影响推荐。

**停止条件：**如果该信息属于身份证件、银行资料、密码、验证码、恢复码或其他不应保留的敏感内容，不要只做文字更正，应直接进入下一步彻底删除。

## 第四步：彻底删除一项不希望保留的信息

只删除一条聊天，通常不够。OpenAI 当前说明，彻底删除某项信息时，需要处理所有可能的来源。

### 1. 删除记忆中的对应内容

在 `Memory summary`、`Manage memories` 或当前页面提供的记忆管理入口中，删除对应条目。若页面提供“Delete and turn off memory”，它会删除摘要中的记忆并关闭记忆，但不会删除过去聊天。

### 2. 删除包含该信息的聊天和归档聊天

回到聊天列表，查找曾经输入该信息的对话。普通聊天和归档聊天都要检查；确认不再需要后再删除。

### 3. 检查上传文件

如果姓名、地址或其他信息来自上传文件，应删除相关聊天或项目中的文件。不要只删除记忆摘要后继续保留原文件。

### 4. 检查连接应用

如果信息来自 Google Drive、SharePoint 或其他连接应用，先在连接应用中处理原内容，再到 ChatGPT 设置中断开不再需要的连接。

### 5. 重新验收

新建普通聊天，询问 ChatGPT 是否仍知道该信息。若仍被提及，继续检查 Custom Instructions、过去聊天、文件和连接应用；不要反复创建新的测试对话并继续提供同一项敏感信息。

OpenAI 可能为安全和调试保留已删除 Saved Memories 的日志最多 30 天。删除记忆也不会改写过去对话中已经生成的文字；需要移除旧对话里的内容时，还要删除对应聊天。

## 第五步：只关闭记忆，但保留聊天历史

如果你希望以后不再使用个性化记忆，但仍想保留普通聊天记录，可以关闭 Memory。

1. 进入 `Settings → Personalization → Memory`；
2. 关闭页面中的 Memory 或 Saved memories 开关；
3. 页面另有 `Reference chat history` 时，核对它是否也已关闭；
4. 新建聊天，确认回答不再主动引用过去偏好。

需要注意：关闭记忆不会删除已经保存的记忆，也不会删除聊天。以后重新打开记忆时，ChatGPT 可能再次从仍保留的旧聊天中形成记忆。因此，不希望保留的信息仍应按上一节处理来源。

## 第六步：开始一次临时聊天

只想讨论一次性问题，且不希望这次对话进入历史或形成记忆时，使用 Temporary Chat。

1. 新建一个聊天；
2. 在页面右上角找到胶囊形的 `Temporary` 按钮；
3. 点击按钮，确认页面已经进入临时聊天模式；
4. 再输入本次问题；
5. 对话结束后，不要把重要结论只留在该窗口，先保存经过核验且不敏感的必要结果。

**预期结果：**临时聊天不会显示在聊天历史中，不会访问或创建个性化记忆，也不会用于改进模型。

但临时聊天不是“完全不留任何记录”。OpenAI 当前说明，出于安全目的，系统仍可能保留副本最多 30 天，并可能在极少数高风险场景使用有限的安全相关上下文；它仍会遵循已经开启的 Custom Instructions。若使用带 Actions 的 GPT，发送给第三方的数据还受第三方隐私政策约束，可能保存更久。

## 第七步：关闭普通聊天的模型训练用途

如果你的目标是保留聊天和记忆，但不希望普通对话用于改进模型，应操作 Data Controls，而不是 Memory。

### 网页端

1. 点击头像；
2. 进入 `Settings → Data Controls`；
3. 关闭 `Improve the model for everyone`；
4. 刷新设置页，确认开关仍为关闭状态。

### 移动端

1. 打开侧边栏；
2. 点击头像；
3. 进入 `Data Controls`；
4. 关闭 `Improve the model for everyone`。

OpenAI 当前说明，这个设置会同步到同一账号的网页端和移动端。关闭后，普通聊天仍会出现在历史中；如果还要求不进入历史、不创建记忆，应使用临时聊天。

## 按使用场景选择正确设置

| 你的目标 | 应该执行的操作 | 完成后怎样验收 |
|---|---|---|
| 让 ChatGPT 继续记住长期偏好 | 开启 Memory，并在摘要中保留正确内容 | 新聊天能正确使用偏好 |
| 更正过期目标或错误信息 | 编辑 Memory summary，并重新询问 | 回答使用新信息，不再引用旧内容 |
| 彻底删除敏感或不需要的信息 | 删除记忆、聊天、文件，并检查连接应用 | 新聊天不再知道该信息 |
| 只进行一次不使用记忆的对话 | 开启 Temporary Chat | 对话不进入历史、不创建记忆 |
| 保留聊天但不用于改进模型 | 关闭 Improve the model for everyone | 历史仍存在，训练开关保持关闭 |
| 设置页没有 Memory | 核对账号、设备、版本、计划和工作区 | 找到正确账号入口，或确认仍在滚动开放 |

## 账号或套餐异常时怎样处理

Memory 入口缺失不一定表示订阅失效。新版记忆会按计划、地区和设备逐步开放，单位工作区也可能由管理员控制。

1. 先确认当前登录方式和账号邮箱；
2. 查看 `Settings → Account` 中的计划状态；
3. 在网页版和最新版 App 中分别检查一次；
4. 若整个账号变成 Free，进入[已付款仍显示 Free 排查]({{ '/guides/chatgpt-paid-but-still-free/' | relative_url }})；
5. 若只有 Memory 入口缺失，而计划仍有效，保留页面截图并联系 OpenAI 支持。

已有有效订阅、成功扣款或待处理交易时，不要为了 Memory 入口再次购买。只有确认当前没有有效或待处理订阅，并且确实需要 Plus 或 Pro 的其他会员能力时，才应查看 [ChongGrok ChatGPT 实时方案](https://chonggrok.com/chatgpt)；ChongGrok 与 OpenAI 无隶属关系，也不能保证某项滚动功能立即出现在所有账号中。

## 不应输入或保留的资料

Memory 的作用是个性化，不是保存密码的工具。无论使用普通聊天还是临时聊天，都不要主动提交：

- ChatGPT 密码、邮箱验证码或恢复码；
- session、Cookie、访问令牌或完整浏览器存储；
- 银行卡完整号码、安全码或身份证件原图；
- 未脱敏的客户资料、医疗记录或公司机密；
- 自己无权上传的文件和聊天记录。

临时聊天能减少个性化和历史留存，但不能把不应分享的数据变成安全数据。涉及第三方 GPT Actions 或连接应用时，还应单独查看对应服务的权限和隐私政策。

## 常见问题

### 关闭 ChatGPT 记忆会自动删除已经保存的内容吗？

不会。关闭记忆只会停止后续个性化使用，不会自动删除已经保存的记忆或原聊天。需要彻底移除某项信息时，还要删除记忆摘要或已保存记忆中的对应内容，并处理包含该信息的聊天、文件和连接应用。

### 删除一条聊天记录，ChatGPT 就会忘记其中的内容吗？

不一定。已保存记忆与聊天记录分开存放，删除聊天并不会自动删除由该聊天形成的已保存记忆。要彻底删除，应同时处理记忆和原始聊天。

### 临时聊天会读取或创建记忆吗？

不会用于个性化记忆。OpenAI 当前说明，临时聊天不会访问或创建个性化记忆，也不会显示在聊天历史或用于改进模型；出于安全目的，系统仍可能保留副本最多 30 天，并可能在极少数高风险场景使用有限的安全相关上下文。

### 临时聊天还会使用自定义指令吗？

会。OpenAI 当前说明，临时聊天仍会遵循已经启用的 Custom Instructions。因此，若自定义指令中含有不希望本次对话使用的信息，应先检查或临时关闭相应指令。

### 关闭 Improve the model for everyone 等于关闭记忆吗？

不等于。该开关控制对话是否用于改进模型；Memory 控制个性化记忆；Temporary Chat 则不会进入历史、不会创建个性化记忆，也不会用于改进模型。三者解决的问题不同。

### 为什么我的账号没有 Memory summary？

账号可能刚启用记忆、聊天历史不足，或新版记忆尚未滚动到当前计划、地区或设备。先以 `Settings` 中实际显示的选项为准，不要仅因入口缺失重复购买订阅。

### 怎样查看 ChatGPT 为什么在回答中提到某项个人信息？

如果回答下方显示书本形状的来源图标，可以点击它查看参与个性化的记忆、历史聊天、文件或自定义指令。该功能处于滚动更新中，页面不显示时可以直接问 ChatGPT 记住了什么，再到设置中核对。
