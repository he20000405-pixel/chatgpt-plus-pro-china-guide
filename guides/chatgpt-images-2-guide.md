# ChatGPT Images 2.0 怎么用？图片生成、局部编辑、文字与透明背景完整指南

**直接答案：**ChatGPT Images 2.0 可以在普通对话中直接生成图片，也可以从 **More → Images** 进入专门入口；已有图片则可以上传后继续编辑。第一次使用时，先写清用途、画面比例、主体、构图、准确文字和背景要求，生成后再逐项核对，不要把“一次生成完成”当成最终验收。

OpenAI 当前说明，ChatGPT Images 2.0 面向所有套餐开放，网页、iOS 和 Android 都可以使用。Free 用户也能生成图片；Plus、Pro 和 Business 还可以使用 **Images with thinking**，付费套餐通常拥有更高的使用上限，但官方没有给出适用于所有账号的固定张数。

> 本文只讨论 ChatGPT 消费端的图片功能，不涉及 OpenAI API。界面名称、使用上限和开放范围可能变化，应以当前账号实际显示及 OpenAI 官方页面为准。

## 先按目标选择正确入口

| 你要完成的任务 | 从哪里开始 | 完成后应检查什么 |
|---|---|---|
| 从零生成一张图片 | 在对话中直接描述图片，或选择 **More → Images** | 主体、构图、比例、文字和背景是否符合要求 |
| 修改 ChatGPT 已生成的图片 | 打开该图片，再进入编辑器 | 目标区域是否改变，其他区域是否被误改 |
| 修改自己已有的图片 | 上传原图，然后描述修改要求 | 原图的重要细节是否保留，是否暴露敏感信息 |
| 改变横版、方形或竖版比例 | 使用 **Aspect ratio**，或在提示中写明比例 | 画面是否被异常裁切，文字是否仍完整 |
| 下载或分享图片 | 从 Images 打开图片，选择 **Save**、**Copy** 或 **Share** | 下载文件能否正常打开，透明背景是否真实保留 |
| 删除 Images 中的图片 | 删除生成该图片的原对话 | 对话和对应图片是否都已移除 |

如果你只是想生成一张新图，从普通对话开始即可。只有在需要局部修改、调整比例或管理历史图片时，才需要进入 Images 或图片编辑器。

## 开始前先完成 4 项准备

### 1. 确认当前登录的是正确账号

先打开 ChatGPT 账号菜单，核对登录邮箱、登录方式和当前套餐。不同账号的 Images 历史和使用上限彼此独立，因此只看浏览器保存的 Google 或 Apple 账号并不够。

**预期结果：**你能确认当前 ChatGPT 账号，并且知道图片最终会保存到哪个账号的 Images 页面。

### 2. 明确图片的实际用途

先确定图片用于文章封面、商品说明、社交平台、演示文稿还是透明背景素材。用途决定比例、留白、文字大小和构图，不能只写“帮我生成一张好看的图”。

### 3. 准备必须保留的内容

把品牌名、标题、日期、产品名称和不能改动的元素单独列出。文字越长、要求越多，越适合分成多轮完成：先确定构图，再修改文字和细节。

### 4. 清理不必要的敏感信息

上传已有图片前，先检查是否包含身份证件、订单号、银行卡资料、登录信息、私人聊天或其他人的个人信息。与修改目标无关的敏感内容应先裁掉或遮挡。

## 第一次生成：按 6 个字段写提示

### 第一步：打开图片生成入口

在 ChatGPT 中可以使用任一方式开始：

1. 新建普通对话，直接输入“请生成一张图片”；
2. 在输入区域选择 **More**，再选择 **Images**；
3. 从侧边栏打开 **Images**，选择 **Create Image**。

**预期结果：**ChatGPT 开始处理图片任务。生成可能需要几分钟，等待期间可以继续使用 ChatGPT。

**如果没有 Images 入口：**先直接在对话中描述要生成的图片。随后更新应用、刷新网页，并确认当前登录账号；不要因为菜单位置不同就立即重新购买会员。

### 第二步：把要求写成完整任务

一条容易核对的提示至少包含六部分：

1. **用途：**图片最终放在哪里；
2. **比例：**横版、方形、竖版或具体宽高比；
3. **主体：**画面中最重要的人、物或场景；
4. **构图：**主体位置、视角和留白区域；
5. **文字：**必须出现的准确文案；
6. **限制：**哪些内容不要出现，哪些元素必须保持清晰。

可以使用下面的模板：

> 请为 `[用途]` 生成一张 `[比例]` 图片。
>
> 主体：`[人物、物品或场景]`。
>
> 构图：`[主体位置、镜头和留白]`。
>
> 画面文字：只写“`[准确文案]`”，不要添加其他文字。
>
> 背景与风格：`[背景、颜色、光线、材质]`。
>
> 保持不变：`[必须保留的元素]`。不要出现：`[排除项]`。

例如，制作文章封面时可以这样写：

> 请生成一张 3:2 的中文文章封面。主题是“ChatGPT 图片生成入门”。标题放在中央安全区，四周保留足够留白；画面文字只写“ChatGPT 图片生成入门”，不要添加价格、网址或官方 Logo。背景使用白色和深绿色，整体清晰、克制，适合知识库文章。

### 第三步：逐项验收第一版

生成后不要立刻下载，先按提示中的六个字段检查：

- 比例是否正确；
- 主体是否完整；
- 构图是否留出需要的空间；
- 文字是否逐字正确；
- 背景是否符合要求；
- 是否出现了不允许的元素。

一次只修改一类问题。例如第一轮只调整构图，第二轮再修正文字。把多个问题塞进一条指令，容易导致已经正确的部分被重新生成。

## 图片中包含文字时这样处理

ChatGPT Images 可以按照指令在图片中加入文字，但“能够生成文字”不等于每次都准确。标题、品牌名、日期和专业术语必须由人逐字核对。

建议按下面顺序处理：

1. 把文字放在引号中，明确要求“只写这段文字”；
2. 一张图尽量只放一个主标题和一个短副标题；
3. 先确认构图，再单独要求修正错字；
4. 每次修改后重新检查全部文字，而不是只看刚改的字；
5. 对准确性要求很高时，保留无文字版本，再用排版工具添加最终文字。

**停止条件：**连续修改仍出现错字，或修改一个字导致其他文字变化时，不应继续反复生成。改用无文字底图加人工排版，结果更容易验收。

## 生成透明背景图片

OpenAI 官方说明，ChatGPT Images 可以按要求生成透明背景。提示中应明确写出“背景必须透明”，并说明需要保留的主体边缘。

例如：

> 生成一个正面视角的深绿色文件夹图标。只保留图标主体，背景必须透明，不要阴影、文字、边框或白色底板。

生成后按下面顺序确认：

1. 从图片控制区选择 **Save** 下载；
2. 用能显示棋盘格透明背景的图片工具打开文件；
3. 检查主体周围是否仍有白色或其他实色背景；
4. 检查细小边缘是否被截断。

如果背景并未真正透明，回到原对话明确指出“当前文件仍有实色背景”，并要求只移除背景、保持主体不变。不要仅凭 ChatGPT 页面中的白色预览判断透明度。

## 编辑已有图片：先决定是否需要选区

ChatGPT 可以编辑生成图片，也可以编辑你上传的已有图片。开始前先保存原图副本，因为编辑可能影响选区以外的内容。

### 方法一：不使用选区，直接描述整体修改

适合改变整体色调、背景、画面比例或全局风格：

1. 打开 ChatGPT 生成的图片，或上传自己的图片；
2. 在对话或编辑器文本框中描述要修改的内容；
3. 同时写明必须保持不变的主体、文字和构图；
4. 生成后与原图并排比较。

示例：

> 把背景改成纯白色。保留人物、服装、姿势、画面文字和主体大小不变，不要添加新元素。

### 方法二：使用 Select 做局部编辑

适合删除小物体、替换局部文字或修改一个区域：

1. 打开图片，进入编辑器；
2. 选择 **Select**；
3. 只涂选需要修改的区域；
4. 使用 **Undo** 或 **Redo** 调整选区；
5. 在文本框中说明该区域要变成什么；
6. 完成后选择 **Save**。

OpenAI 明确说明，选区并不总是精确，修改可能扩展到选区以外。为了降低误改风险，应缩小选区，并在指令中写明“选区外全部保持不变”。

**异常分支：**如果选区外仍被修改，返回原图，把任务拆成更小的区域重新操作。不要在已经变形的版本上连续叠加修改。

## 在手机上进行局部编辑

iOS 和 Android 的操作顺序与网页端略有不同：

1. 在 ChatGPT App 中打开一张生成图片；
2. 选择 **Edit**，可以直接描述整体修改；
3. 需要局部修改时选择 **Select**；
4. 用滑块调整选择工具大小；
5. 使用 **Undo** 或 **Redo** 修正选区；
6. 选区完成后选择 **Next**；
7. 在对话面板中描述要修改的内容。

**预期结果：**修改集中在选中区域附近，同时返回一个可以继续保存或编辑的新版本。

**如果按钮名称不同：**先更新 ChatGPT App，并以当前界面为准。网页、iOS 和 Android 的入口位置可能随版本调整。

## 调整横版、方形或竖版比例

可以在生成前把比例写进提示，也可以在编辑器中使用 **Aspect ratio**。选择比例后要重新检查画面，因为改变比例可能让主体位置、留白和文字布局发生变化。

常见选择方式：

| 使用场景 | 建议写法 | 重点检查 |
|---|---|---|
| 文章或社交预览图 | “生成 3:2 横版图片” | 标题是否位于中央安全区 |
| 方形头像或帖子 | “生成 1:1 方形图片” | 主体边缘是否被裁切 |
| 手机竖版信息图 | “生成 2:3 竖版图片” | 长文字是否过小或重叠 |
| 演示文稿配图 | “生成 16:9 横版图片” | 关键元素是否避开页边 |

比例只是构图要求，不代表固定像素或打印质量。下载后仍应查看实际文件尺寸，再决定是否满足发布平台要求。

## 保存、查找与删除图片

OpenAI 当前说明，ChatGPT 生成的图片会自动保存到 **Images**。打开图片后可以使用：

- **Copy：**复制到剪贴板；
- **Save：**下载到本地设备；
- **Share：**发送到其他应用。

要从 My images 删除图片，需要删除生成该图片的对话：

- 网页端：把鼠标移到对话标题，打开更多菜单，选择 **Delete**；
- iOS 或 Android：长按对话标题，再选择 **Delete**。

删除对话前先下载需要保留的图片。不要假定只删除对话文字而图片仍会留在 Images 中。

## 常见问题按这个顺序排查

### 情况一：看不到 Images 入口

先在普通对话中直接输入图片要求。如果可以生成，说明功能可用，只是入口位置不同。

仍无法使用时依次检查：

1. 是否登录了正确 ChatGPT 账号；
2. 网页是否已经刷新，App 是否已更新；
3. 当前工作区是否限制图片功能；
4. 页面是否显示明确的使用上限提示。

OpenAI 当前说明 Images 2.0 面向所有套餐开放，因此缺少单独菜单不等于必须购买会员。完成上述检查仍无法生成时，再保存报错文字和脱敏截图联系 OpenAI Support。

### 情况二：图片一直显示正在生成

复杂图片可能需要几分钟。先等待当前任务完成，不要连续提交相同提示。

如果长时间没有结果：

1. 检查对话是否显示报错或需要修改提示；
2. 刷新一次页面；
3. 新建一个简单测试，例如“生成一个白底绿色圆形”；
4. 简单测试也失败时，查看 [OpenAI 服务状态](https://status.openai.com/)并稍后再试。

不要同时创建多个相同任务，否则难以判断哪一次生成成功，也会消耗可用次数。

### 情况三：页面提示达到图片生成上限

图片生成拥有独立于普通文字聊天的使用上限。Free 的上限通常低于付费套餐，但实际限制可能随账号和系统状态变化。

正确处理方式是：

1. 停止继续提交图片任务；
2. 记录页面显示的提示；
3. 按界面提示等待恢复；
4. 恢复后先提交一个简单任务验证。

已有有效订阅、成功扣款或待处理交易时，不要再次购买。账号显示 Free，或会员权益没有显示在当前登录账号上时，应先阅读[已付款但仍显示 Free 排查]({{ '/guides/chatgpt-paid-but-still-free/' | relative_url }})。

### 情况四：图片中的文字有错字

先确认提示中使用了准确文字和引号。然后只要求修改错误文字，并明确其他内容保持不变。

连续修改仍不准确时，应停止图片内文字生成，下载无文字底图并使用排版工具添加文字。需要发布的标题、价格、日期和品牌名必须人工逐字检查。

### 情况五：局部编辑改变了整张图

这属于官方已说明的编辑器限制。返回原图，缩小选区，把修改拆成一步，并明确选区外保持不变。若仍无法控制，就不要在错误版本上继续修改。

### 情况六：下载后没有透明背景

先用能显示棋盘格透明背景的图片工具检查文件，而不是只看白色网页背景。确认仍为实色后，回到原对话要求仅移除背景；主体边缘出现缺口时，应同时要求恢复完整边缘。

### ChatGPT Free 可以使用 Images 2.0 吗？

可以。OpenAI 当前说明 Images 2.0 面向所有套餐开放。Free 的图片生成上限更严格，达到上限后应按界面提示等待。

### ChatGPT Images 应该从哪里打开？

可以在普通对话中直接描述图片，也可以选择 **More → Images**。已经生成的图片会自动保存在 Images 页面。

### 可以上传自己的图片再修改吗？

可以。上传后直接描述修改要求，或者使用 Select 标出需要修改的区域。上传前先清理与任务无关的个人或账号信息。

### 为什么选区以外也发生了变化？

OpenAI 明确说明选区不一定精确，编辑可能扩展到选区之外。返回原图、缩小选区，并明确选区外保持不变。

### 如何删除 Images 中的图片？

删除生成该图片的对话。网页端使用对话标题的更多菜单；iOS 或 Android 长按对话标题后选择 Delete。

### 官方 DALL·E GPT 停用后还能生成图片吗？

可以。OpenAI 计划在 **2026 年 8 月 30 日**停用官方 DALL·E GPT，ChatGPT Images 仍继续用于图片创建和编辑。需要保留的旧图片应在该日期前下载。

### ChatGPT Images 可以在 Codex 中使用吗？

可以。OpenAI 当前帮助文档说明，Codex 也支持图片生成和编辑。需要使用 Codex 完成本地项目时，可先阅读[ChatGPT Plus / Pro 使用 Codex]({{ '/guides/chatgpt-codex-app-cli-ide/' | relative_url }})，并在操作前确认文件范围和权限。
